# AGENTS.md — riplog-nuxt

## Commands

```bash
pnpm dev          # start dev server (http://localhost:3000)
pnpm build        # production build
pnpm generate     # static site generation
pnpm preview      # preview production build
pnpm lint         # eslint . (check)
pnpm lint:fix     # eslint . --fix (auto-fix)
```

No `test` script exists. Always run `pnpm lint` after code changes.

## Architecture

- **Nuxt v4** with `app/` directory layout — pages, layouts, components live inside `app/`, NOT at the project root. This differs from Nuxt v3.
- **Nuxt Content v3**: content in `content/`, queried via `queryCollection('content')` (NOT the v2 `queryContent()`). Content stored in SQLite at `.data/content/contents.sqlite`.
- **Catch-all route**: `app/pages/[...slug].vue` maps every path to `queryCollection('content').path(route.path).first()`. No static pages defined. Adding a static page (e.g. `app/pages/about.vue`) takes priority over the catch-all.
- **MDC components**: Vue components in `app/components/` are auto-available in markdown via `:ComponentName` or `::ComponentName{prop="val"}` syntax.
- **Tailwind CSS v4**: no `tailwind.config.ts` — config is CSS-first via `@import "tailwindcss"` and `@theme` blocks in `~/assets/css/main.css`.

## Conventions

- **Package manager**: pnpm (lockfile: `pnpm-lock.yaml`)
- **ESLint flat config** generated by `@nuxt/eslint`. Custom rules extend the generated base via `eslint.config.mjs`.
- **Stylistic rules**: double quotes, semicolons (configured in `nuxt.config.ts` under `eslint.config.stylistic`). ESLint is the formatter — no Prettier.
- **VS Code**: `.vscode/settings.json` runs `source.fixAll.eslint` on save for js/ts/vue.
- **Path aliases**: `~` and `~~` both resolve to project root (standard Nuxt)

## Stack

- **UI**: @nuxt/ui v4 (wraps app in `<UApp>`, components like `<UHeader>`, `<UNavigationMenu>`)
- **Content**: @nuxt/content v3, zod v4 for schema validation in `content.config.ts`
- **ORM**: drizzle-orm + better-sqlite3 (local), targets Cloudflare D1 in production
- **Deployment**: Cloudflare (Workers/D1/KV/R2) via @nuxthub/core + wrangler. Hub bindings (db, kv, blob, cache) currently commented out in `nuxt.config.ts`.

## Gotchas

- ESLint config imports `.nuxt/eslint.config.mjs` (generated). Fresh clones need `pnpm dev` once or `pnpm exec nuxt prepare` before `pnpm lint` works.
- `pnpm-workspace.yaml` `allowBuilds` for `workerd` has placeholder text `"set this to true or false"` — may need fixing for wrangler to function.
- No CI pipelines defined (no `.github/workflows/`).
- No testing framework configured.
- No `.env.example` — environment variables for Cloudflare bindings not yet documented.
