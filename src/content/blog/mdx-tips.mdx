import Blink from "../../components/Blink.astro";

export const favoriteSites = ["GeoCities", "Angelfire", "Tripod", "Homestead"];

Components in `src/components/mdx.ts` are auto-injected, but you can still `import` anything
you like at the top of a post, and even `export` values:

<ul>
  {favoriteSites.map((s) => (
    <li>
      <Blink>{s}</Blink>
    </li>
  ))}
</ul>

Put post-specific components next to the post, or in `src/components/`. Posts can live in
subfolders too; the folder path becomes part of the URL.

The current year according to this post is **{new Date().getFullYear()}** (evaluated at build time).
