## How it works

Every post is an **MDX** file in `src/content/blog/`. That means regular Markdown, plus
components. These components (listed in `src/components/mdx.ts`) are available in every
post without imports:

| Component               | What it does                  |
| ----------------------- | ----------------------------- |
| `<Blink>`               | Brings back the `<blink>` tag |
| `<Marquee>`             | Scrolling text, CSS-animated  |
| `<Rainbow>`             | Animated rainbow text         |
| `<New />`               | Blinking NEW! badge           |
| `<UnderConstruction />` | The classic construction sign |

Here's one in action: <Blink color="var(--yellow)">THIS TEXT BLINKS</Blink> <New />
